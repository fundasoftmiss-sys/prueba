 # Proyecto de ejemplo

Este repositorio contiene un ejemplo básico de un proyecto de microservicios.

## Descripción

El objetivo de este proyecto es mostrar una estructura sencilla para practicar la creación, organización y documentación de servicios independientes.

## Contenido

- `ejemplo.html`: página HTML de ejemplo.
- `readme.md`: documentación del proyecto.

## Uso

Clona el repositorio y abre `ejemplo.html` en un navegador para visualizar el ejemplo.

## Estado del proyecto

Este proyecto tiene fines educativos y puede ampliarse con nuevos servicios, configuraciones y documentación.
